# 网络政策

> 本文为 [network.md](network.md) 的中文译本，仅供参考。如中英文表述存在歧义或冲突，以英文版为准。

本页说明 Xtra Computing 服务器的网络与防火墙配置。

> [!WARNING]
> 端口可用性受 NUS 计算机学院防火墙政策约束，该政策可能在不事先通知的情况下变更。请始终以 NUS 官方防火墙文档中的最新规则为准：https://dochub.comp.nus.edu.sg/cf/tech/network/firewall

## 开放端口

### 系统保留端口

以下端口由服务器基础设施使用，**不可**用于用户服务。

| 端口 | 协议 | 用途 |
|------|------|------|
| 22 | TCP | SSH 访问（有速率限制） |
| 111 | TCP/UDP | autofs |
| 2049 | TCP/UDP | NFS |
| 2379 | TCP | etcd 客户端（用量上报） |
| 2380 | TCP | etcd 节点间通信（用量上报） |
| 4000 | TCP | Cgroup Exporter（内存监控） |
| 4001 | TCP | Node Exporter（CPU 及通用监控） |
| 4003 | TCP | NVIDIA GPU Exporter（GPU 监控） |

### 用户可用端口

用户可在以下端口范围内运行服务：

| 端口范围 | 协议 | 说明 |
|----------|------|------|
| 4000-4100 | TCP/UDP | SoC 允许的范围。请避开上文列出的系统保留端口。 |
| 10000-30000 | TCP/UDP | 用户服务通用范围。 |

上述范围之外的端口默认被封锁。

## 用户责任

- 仅绑定上文所列用户可用范围内的端口。
- 不得干扰系统保留端口或相关服务。
- 服务不再需要时应及时终止并释放端口。
- 如需使用允许范围之外的端口，请联系管理员。是否批准取决于 NUS 防火墙政策。
